# Security review

✅ One self-review of the whole repository, dated 2026-09-14 and checked against the code again on 2026-09-27 (`.github/workflows/dependencies.yml` runs the audits it relies on). The criteria are two current lists, versions pinned so that a later reader can tell whether they are out of date: the **OWASP Top 10:2025** (final; OWASP marks the 2021 edition superseded, and SSRF is no longer a category of its own but part of A01) and the **OWASP Top 10 for Large Language Model Applications, 2026 edition** (published 2026-08-04 by the OWASP GenAI Security Project; it replaces the 2025 edition) (both outside the repository). Why OWASP and not ISO 27001 or NIST: [decisions.md](decisions.md), 2026-09-14, *Progress moves into GitHub issues*, point 3.

This file owns the **coverage**: what each item of the two lists was judged to be in this project. The findings themselves are GitHub issues labelled `security`. Every row below falls into one of three kinds — sound (with the grounds), an open finding (with the issue), or a gap (with the issue). There is no fourth kind.

## OWASP Top 10:2025

| Category | Verdict | Where |

| A01:2025 Broken Access Control | 🔶 3 open findings | `#4` (fetching any URL with no destination allowlist — the 2021 A10 SSRF belongs here since the merge) · `#15` (a manifest value joined into a path without normalisation) · `#17` (a shared index, no per-user attribution). Judged sound: authorisation and IDOR (scoping at the queryset, a 404 that cannot be told from "does not exist") · staff scopes (a scope outside the caller's roles is a 404 and a permission missing inside it a 403, both before the body is read, `apps/roles/api.py`; who may grant a role is the assign table of `apps/roles/registry.py`; the admin admits superusers only; every route declares who may call it, `tests/test_route_permissions.py`) · serving a cited PDF (looked up by sha256 in the parse sidecars, resolved and kept inside the corpus directory, never from a client path, a 404 for every miss: `apps/qa/sources.py`; that any logged-in account can read a whole deck is decided and priced in [decisions.md](decisions.md), 2026-09-29, *A slides citation opens its whole PDF, and a conversation is deleted outright*, point 1) · CSRF end to end (both directions, `ensure_csrf_cookie` plus the request header, and the Vite proxy's `changeOrigin: false` for a reason — CSRF joined this category in 2021) · the crawler's outbound posture (robots and throttling are in code, not in a convention) |
| A02:2025 Security Misconfiguration | 🔶 3 open findings | `#11` (no CSP) · `#14` (error messages tell the caller server commands and paths) · `#16` (in part: the `DEBUG` default of `.env.example` keeps `BasicAuthentication` on). Sound: `check --deploy --fail-level WARNING` passes · `docker-compose.yml` has no plain-text credentials and exposes no application service by default · Qdrant, which has no API key, is published on the loopback interface only, with CORS off so a web page in the host's browser cannot call it (`docker-compose.yml`) · the three workflows get read-only tokens only where needed: `ci.yml` and `dependencies.yml` have `contents: read`, `secrets.yml` adds `pull-requests: read` (gitleaks lists a pull request's commits to scope its scan and gets a 403 without it; **write is not granted** — that would be for posting comments) · no checkout leaves the token in `.git/config` (`persist-credentials: false`) · zizmor and actionlint lint the workflows at commit time and in the `hooks` step (`.pre-commit-config.yaml`) · `makemigrations --check --dry-run` guards against migration drift |
| A03:2025 Software Supply Chain Failures | 🔶 1 open finding | `#10` (Hugging Face models not pinned to a revision). Four advisories in the lockfiles are **accepted risks**, not fixes: `accelerate`'s PYSEC-2026-3804, which no scanner reports on 1.15.0 ([decisions.md](decisions.md), 2026-10-06, *`accelerate` moves to 1.15.0*), and `docling`'s CVE-2026-105750 and CVE-2026-105751 until docling reaches their fixes, the second out of reach behind converters that admit PDFs only, the first because nothing sets `render_page` and only streams reach the HTML backend ([decisions.md](decisions.md), 2026-10-06, *`docling`'s two file-disclosure advisories*), and `katex`'s GHSA-238p-pmpm-9mq7, held until `rehype-katex` accepts its fix ([decisions.md](decisions.md), 2026-10-06, *Dependabot holds the whole docling family and katex*); the two `transformers` ones are fixed by the lockfile's darwin fork ([decisions.md](decisions.md), 2026-10-05, *`transformers` reaches its fixes through a lockfile that resolves darwin apart*). This category extends the 2021 A06 "Vulnerable and Outdated Components", which is why the unpinned revision moves here from the 2021 A08. Sound: `uv sync --locked` · `npm ci` · actions pinned by SHA · dependency checks in two layers (`.github/workflows/dependencies.yml`): `dependency-review`, a required check, fails a pull request that brings in a vulnerable version, and pip-audit over the lockfile's Linux resolution with `npm audit --omit=dev --audit-level=high` runs on `main` and weekly, while Dependabot's alerts read both lockfiles whole · monthly update pull requests from `.github/dependabot.yml`, each version at least seven days old |
| A04:2025 Cryptographic Failures | ✅ sound | under `check --deploy`: HSTS, SSL redirect and secure cookies; `SecretStr` used where it should be (`config/env.py`); no token stored on the client (`localStorage` holds no token, only same-origin cookies exist) (`config/settings.py`) |
| A05:2025 Injection | ✅ sound | no raw queries, only the ORM and `models.Filter`; the frontend has no `dangerouslySetInnerHTML`; answers render through `react-markdown` without `rehype-raw`, so raw HTML stays text, `safeUrl` keeps only absolute http(s) links, which open with `rel="noopener noreferrer"` and show a host their text hides, and images in an answer are not loaded (`frontend/src/features/chat/AnswerMarkdown.tsx`); KaTeX keeps its default `trust: false`, and its HTML is parsed in an inert `<template>` and reaches the page as React elements (`frontend/src/features/chat/MathMarkdown.tsx`); `CSS.escape()` is used; two `subprocess.run` calls outside tests, both with a fixed argv and no shell (`rag/live.py`, `scripts/check.py`) |
| A06:2025 Insecure Design | 🔶 1 open finding | `#5` (a permanent write entrusted to an LLM verdict that reads the very content it judges — an LLM as the authorisation decision). Numbered A04 in 2021. **What exists**: the gate fails closed (`relevant=False` when its reply does not validate); every live write carries its run id and is rolled back in one call (`delete_by_run()`); evaluation reads the crawl snapshot by default. |
| A07:2025 Authentication Failures | 🔶 2 open findings | `#9` (unlimited login attempts on `/admin/`) · `#16` (`BasicAuthentication` is active whenever `DEBUG` is true, which `.env.example` sets; the code default is false). Sound: `create_user` · Django's four password validators · session key rotation · one failure message for every case · DRF `ScopedRateThrottle` with `NUM_PROXIES = 0`. Named "Identification and Authentication Failures" in 2021 |
| A08:2025 Software or Data Integrity Failures | ✅ sound | no `pickle`, `torch.load`, `yaml.load` or `eval`; JSONL is always read with `model_validate_json`, and bad registry or manifest rows are skipped with a warning; no secret in the repository or its history, `.env` never tracked, pre-commit runs `detect-private-key` (`.pre-commit-config.yaml`); GitHub's secret scanning, with push protection, checks every push on the server against each provider's token formats, and gitleaks checks this side with generic rules, over a pull request's commits and over the whole history weekly (`.github/workflows/secrets.yml`). Model-artefact integrity is A03's `#10` |
| A09:2025 Security Logging and Alerting Failures | 🔶 1 open finding | `#13` (authentication events leave no log). Named "Security Logging and Monitoring Failures" in 2021. **What exists**: logging is configured for Django (`config/settings.py`, `LOGGING`) and for the `rag/` command lines; the agent keeps an append-only decision log. |
| A10:2025 Mishandling of Exceptional Conditions | 🔶 gap | **What exists**: several deliberate fallbacks — a failing relevance gate means `relevant=False` (failing closed) · one validation point for the LLM's JSON output, a deterministic fallback at each caller and a 30 s timeout · an explicit `Unavailable` in the contract that tells "retry later" from "a service the answer needs is missing" · the router falling back to `both` on a failed validation. **What is missing**: a verdict. The category is new in 2025 (the 2021 slot was SSRF), and the fallbacks do not fail the same way: the gate fails closed, while bad registry and manifest rows are skipped with a warning, carrying on with partial data → `#52` |

## OWASP Top 10 for LLM Applications 2026

| Category | Verdict | Where |
| --- | --- | --- |
| LLM01:2026 Prompt Injection | 🔶 2 open findings | `#5` (indirect injection aimed at the **write decision**) · `#6` (indirect injection aimed at the **answer**: retrieved excerpts enter the generation prompt without delimiters). **What exists**: every model decision that acts (route, gate, pick) is JSON validated by pydantic, with a deterministic fallback; there is no native tool calling; the deepening loop fetches at most 3 pages, chosen from the registry's link graph. |
| LLM02:2026 Sensitive Information Disclosure | 🔶 2 open findings | `#36` · `#14` (in part: error messages disclose server paths and commands). **What is sound**: the index holds public campus pages and the course slides, both readable by every account, and no private per-user material, because upload **does not exist in the code** (no `FileField`, no endpoint). **What is missing**: once upload exists this row has to be judged again, which is an acceptance item of `#36`. The gates it will need have precedents: `LIVE_MAX_PDF_PAGES = 40`, the 120 s `document_timeout`, `artifact_name()` fixing the file name on disk |
| LLM03:2026 Excessive Agency | 🔶 gap | the deepening loop in `rag/agent.py` is constrained (a hard cap of 3 steps · explicit control flow · a pydantic-validated JSON decision at each step · ⛔ native tool calling · its one write, `decisions.jsonl`, is an audit artefact) but has **never been assessed against this category**, which rose from 6th to 3rd in 2026 → `#53` |
| LLM04:2026 Supply Chain | 🔶 1 open finding | `#10` (models not pinned to a revision). The dependency side is A03:2025, its accepted risks included. **What exists**: Python packages are pinned by `uv.lock` and installed with `--locked`; the models are named, not pinned to a revision. |
| LLM05:2026 Data and Model Poisoning | 🔶 2 open findings | `#5` — automatic growth is this project's poisoning surface; the mitigation decided on 2026-09-14 is a human confirmation step (`#48`; [decisions.md](decisions.md), 2026-09-14, *A person confirms what automatic growth proposes; the interface is graded*, point 1) · `#17` (in part: with no attribution on the shared index, a poisoned point reaches every account). **What exists**: every live write is tagged `ingest_source="live"` with its run id, so a run is rolled back in one call (`delete_by_run()`), and evaluation reads the crawl snapshot by default (the eval-isolation rule). |
| LLM06:2026 Unbounded Consumption | 🔶 2 open findings | `#8` (the size cap applies only once the whole response body is in memory) · `#12` (registration is open and the queue has no global cap). Numbered LLM10 in 2025. **What exists**: per-endpoint throttles (`ask` 4/min, `auth` 5/min, `config/settings.py`), questions of at most 1000 characters (`apps/qa/serializers.py`), a history window of 3 turns, one answer at a time, where a request that waits more than 90 s for the running one gets a 503 (`QUEUE_TIMEOUT_SECONDS`, `apps/qa/engine.py`), and a 30 s ceiling per LLM request. |
| LLM07:2026 Misinformation | 🔶 gap | **What exists**: ⛔ generating and grading exercises (the most dangerous use is absent) · answers are generated only from retrieved excerpts · citation cards come from retrieval, not from the model's prose (`frontend/src/features/chat/AnswerStream.tsx` states the distinction) · the router refuses with a reason. **What is missing**: a verdict. `#20` measures average quality, not what a wrong deadline in one answer costs → `#56`. Numbered LLM09 in 2025 |
| LLM08:2026 Hidden Context Exposure | 🔶 gap | 2026 widens 2025's "System Prompt Leakage" to any content assembled into the model's context that the user does not see, retrieved text, tool schemas and process rules included; this project's context holds all three → `#54`. **What exists**: the prompts hold no secret or credential, and the router sees only the student's questions, never the answers. |
| LLM09:2026 Vector and Embedding Weaknesses | 🔶 1 open finding | `#17` (a shared index where no point records who caused it). `#17` was first classed under LLM04 Data and Model Poisoning (LLM05 in 2026), which names the consequence; isolation and provenance in a shared vector store are this category. **What exists**: every web point carries its provenance (`ingest_run_id`, `ingest_source`, `trigger`), so a run can be found and rolled back; what is missing is who caused a live write. |
| LLM10:2026 Improper Output Handling | ✅ sound | one validation point for the LLM's JSON output, a deterministic safe fallback at each caller, a 30 s timeout (`rag/llm.py`); rendering on the frontend is A05:2025. Numbered LLM05 in 2025 |
